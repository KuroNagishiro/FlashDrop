# 纯局域网、零账号、零云端

FlashDrop 是自己用的工具，第一版不引入账号体系、推送服务、崩溃上报或任何服务端依赖；发现与传输都发生在同一子网内，安装包手动分发。做产品该有的那套（登录、隐私政策、商店审核、自动升级）会把「打开就能传」拖成带登录和冷启动的流程，与唯一在意的「好用」冲突。

**Considered Options**

- 轻量账号 + 中继服务：可跨网段、可离线投递，但引入登录步骤与服务端运维，且家里私有 WiFi 下没有实际需求。

**Consequences**

- 两端必须同时在线且在同一子网；跨网段、公网中转、离线队列明确不在范围内。
- V1 只保留文件投递与文字投递两类功能，不做远程浏览、双向同步、传输后预览等衍生功能。
