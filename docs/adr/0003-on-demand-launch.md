# 按需启动，不做常驻后台

两端都只在需要传文件时由用户手动打开，退出即停止发现与接收；不做开机自启、常驻托盘，也不做系统右键菜单与分享面板入口。主路径固定为「打开 App → 选文件 → 发送」。

**Considered Options**

- 常驻后台 + 系统级入口：能把发送压到 2 次交互，但引入自启、后台保活与权限申请，且用户明确要求「软件只在需要的时候启动」。

**Consequences**

- 接收端必须先打开 App 才能被发现和投递，实际步骤数包含两端各打开一次。
- 接收期间仍需要前台保活，避免移动端退到后台或锁屏后被系统冻结导致传输中断。
- 首次启动时要把本地网络权限一次性申请掉，否则「自动发现」会在无提示的情况下静默失败。
