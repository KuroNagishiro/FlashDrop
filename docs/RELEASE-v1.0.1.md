# FlashDrop v1.0.1

2026-11-16

## 桌面端（Windows）

- **新增拖拽发送**：从资源管理器选中文件或文件夹，直接拖进 FlashDrop 窗口任意位置即加入待发送列表，重复项自动忽略，中文名与含空格的路径均支持。
- **拖放降级**：环境缺少 `tkinterdnd2` 时仍然可用「选文件」按钮，窗口标题会标注「拖放未启用」，不会卡死。
- 界面为横向双栏（左发送 / 右接收），一屏内无需滚动，底部状态栏与进度条固定可见。

## 手机端（Android）

- **修复「打开接收文件夹」进错目录**：此前只发送通用目录意图，小米文件管理器会忽略路径直接打开 `Download`；现在显式调用系统 DocumentsUI 按目录 ID 直达 `Download/FlashDrop`。
- 兜底顺序：DocumentsUI → 任意文件管理器 → SAF 定位该目录。

## 版本说明

- APK `versionName` 由构建迭代号 `1.3` 统一为发布编号 `1.0.1`，`versionCode` 4 → 5，可直接覆盖安装。
- 桌面端 exe 本次无代码变更，与 v1.0.0 之后的功能提交一致。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `FlashDrop.exe` | 约 14 MB 单文件，双击即用，不需要 Python |
| Android | `FlashDrop.apk` | versionCode 5，传至手机安装 |

首次运行 Windows 会弹一次防火墙提示，请点「允许」，否则手机发现不到电脑。
Android 首次打开需允许「本地网络」与「通知」权限（Android 17 强制本地网络权限）。
